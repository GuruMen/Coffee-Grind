# Регламент сборки
Фиксировать SHA исходников и версию. Установить зависимости, выполнить существующие тесты, собрать артефакт, проверить запуск, вычислить SHA256, сохранить логи. Windows: Python 3.12 и существующий PyInstaller workflow, если применимо. Android: Gradle wrapper, unit tests и assembleDebug при наличии конфигурации. Не публиковать релиз автоматически. Отсутствие исходников или тестов — блокер, а не успех.
