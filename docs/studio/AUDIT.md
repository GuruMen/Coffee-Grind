# Пакет независимого аудита
Передать только утверждённые требования, точный SHA, исходники, артефакт и объективные логи. Не передавать выводы разработчиков. Аудитор фиксирует Critical/High/Medium/Low, шаги воспроизведения, доказательства и непроверенное. Финальная приёмка в свежем изолированном контексте. Android. Приёмка: калькулятор помола, BLE-весы, разрешения, отключение/переподключение, сохранение данных, отсутствие утечки секретов. Проверить на реальном устройстве.
