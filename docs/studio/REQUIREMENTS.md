# Требования и критерии приёмки (черновик)
Android. Приёмка: калькулятор помола, BLE-весы, разрешения, отключение/переподключение, сохранение данных, отсутствие утечки секретов. Проверить на реальном устройстве.
Каждый сценарий: входные данные, шаги, ожидаемый результат, фактический результат, доказательство. Непроверенное не считать пройденным. Производительность измерять на согласованном слабом ПК; пороги согласовать отдельно.
