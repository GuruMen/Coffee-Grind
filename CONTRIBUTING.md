# Руководство по участию в разработке (Contributing Guide)

Спасибо за ваш интерес к развитию **Coffee Grind Calculator & Coffee Bean Journal**! Проект полностью открыт (Open Source) под лицензией MIT, и мы рады любым улучшениям — от добавления новых моделей кофемолок и рецептов заваривания до исправления ошибок и доработки UI.

---

## 🌟 Чем можно помочь проекту?

1. **Добавление новых кофемолок и калибровок**:
   - Если вышла новая ручная или электрическая кофемолка (1Zpresso, KINGrinder, Timemore, Comandante, Fellow, Mahlkönig и др.), вы можете добавить её калибровку в `app/src/main/assets/coffee_data.json`.
2. **Новые протоколы таймера заваривания**:
   - Добавление авторских рецептов мировых чемпионатов бариста (WBrC / WAC) в `BrewProtocol.kt`.
3. **Улучшение UI/UX и переводов**:
   - Развитие экранов на Jetpack Compose (Material 3) и локализация интерфейса.
4. **Сообщения об ошибках (Bug Reports)**:
   - Если вы заметили неточность в пересчёте кликов или ошибку в работе таймера — создайте Issue с указанием модели кофемолки и шагов воспроизведения.

## 🛠 Как развернуть проект локально

1. **Склонируйте репозиторий**:
   ```bash
   git clone https://github.com/<ВАШ_ЛОГИН>/coffee-grind-calculator.git
   cd coffee-grind-calculator
   ```

2. **Откройте проект в Android Studio**:
   - Рекомендуется Android Studio Ladybug / Koala или новее.
   - JDK 17 или 21.
   - Дождитесь синхронизации Gradle.

3. **Запустите сборку и тесты**:
   ```bash
   # Сборка отладочного APK
   gradle assembleDebug

   # Запуск модульных и Robolectric-тестов
   gradle :app:testDebugUnitTest
   ```

## 📐 Как добавить новую кофемолку в базу (`coffee_data.json`)

Все 228 моделей хранятся в массиве `grinders_compact` внутри файла `app/src/main/assets/coffee_data.json`. Каждая запись представляет собой массив следующей структуры:

```json
[
  "Brand",               // 0: Бренд (например, "1Zpresso")
  "Model",               // 1: Модель (например, "K-Ultra")
  "@HCG/...",            // 2: Ссылка на страницу модели
  "Unit",                // 3: Тип шкалы (например, "Rotations.Number.Tick")
  "Note",                // 4: Примечание по шагу в мкм и калибровке
  0,                     // 5: Минимальный размер частиц (min_um)
  1400,                  // 6: Максимальный размер частиц (max_um)
  "1z_10_10",            // 7: Код форматтера шкалы (см. GrinderCalculator.kt)
  1.0,                   // 8: Шаг регулировки (step)
  0,                     // 9: Сохранять ли .0 на целых числах (keep_zero: 0 или 1)
  0.0,                   // 10: Мин. позиция ползунка (min_pos)
  100.0,                 // 11: Макс. позиция ползунка (max_pos)
  "0.0.0",               // 12: Строка начала шкалы (min_scale)
  "1.0.0",               // 13: Строка конца шкалы (max_scale)
  [[0, 0.0], [760, 100.0]], // 14: Опорные точки кусочно-линейной интерполяции [мкм, позиция]
  ["...", "..."],        // 15: 13 строк диапазонов для каждого метода заваривания
  [[...], [...]]         // 16: Числовые диапазоны [low_pos, high_pos, mid_pos, mid_str]
]
```

## 🔄 Процесс отправки изменений (Pull Request)

1. Сделайте **Fork** репозитория.
2. Создайте ветку для вашей задачи:
   ```bash
   git checkout -b feature/add-new-grinder
   ```
3. Внесите изменения и убедитесь, что проект собирается и проходит тесты (`gradle :app:testDebugUnitTest`).
4. Сделайте коммит с понятным описанием:
   ```bash
   git commit -m "feat: add new grinder model to database"
   ```
5. Отправьте ветку в свой форк и откройте **Pull Request**.
